# MagWer Magic Cut

Вирізає з відео паузи й паразитні звуки («е-е-е») і кладе результат поряд:

```bash
magcut відео.mp4              # тиша           -> відео-edited.mp4
magcut відео.mp4 --fillers    # тиша + екання  -> відео-edited.mp4
```

Або через ПКМ у Dolphin: **MagWer Video Toolbox → Вирізати тишу / Вирізати тишу та екання**.

**Структура:**

```
magcut/       ядро
  cli.py          команда magcut — усе запускається звідси
  media.py        ffmpeg: тривалість, silencedetect, рендер
  transcribe.py   медіа        -> *.words.json   дорого, GPU, раз на відео
  regions.py      *.words.json -> список ділянок дешево, stdlib, скільки завгодно
kdenlive/     надбудова — застосувати ділянки до проєкту .kdenlive замість рендеру
tests/        self-checks, без фреймворків
```

Пайплайн навмисно розрізаний надвоє: **прохід по GPU робиться раз**, а пороги крутяться
скільки завгодно разів по готовому JSON. Формат обміну — `<початок> <кінець>` у секундах,
по рядку на ділянку.

```nix
# flake.nix
```

## 1. Вирізати — команда `magcut`

```bash
magcut відео.mp4                          # тиша: −20 dB, паузи від 0.66 с
magcut відео.mp4 --fillers                # + екання «е-е-е» (потрібен GPU, перший раз повільно)
magcut відео.mp4 --noise -25 --pad 0.3    # менш агресивно, більше паузи лишити
```

Результат — `відео-edited.mp4` поряд з оригіналом. Оригінал не чіпається.

| прапорець | дефолт | що робить |
|---|---|---|
| `ВІДЕО` | — | mp4/mkv/mov/webm, або `.kdenlive` (тоді працює надбудова з розділу 4) |
| `--fillers` | вимкнено | додатково різати екання — транскрибує відео через whisper |
| `--noise DB` | `-20` | поріг гучності: тихіше за нього = тиша |
| `--min-silence SEC` | `0.66` | найкоротша тиша, яку варто різати |
| `--pad SEC` | `0.17` | скільки паузи лишити з кожного боку розрізу |
| `--language CODE` | автовизначення | мова транскрипту, напр. `uk` (лише з `--fillers`) |
| `--model NAME` | `large-v3` | модель whisper (лише з `--fillers`) |
| `--out FILE` | `<відео>-edited.mp4` | інший шлях результату |

Що звідки береться: **паузи — завжди `ffmpeg silencedetect`** (виміряно: амплітуда знаходить їх
більше й з тіснішими межами, ніж транскрипт), **екання — транскрипт + гучність** (вони гучні, тож
амплітуді невидимі; деталі в розділі 3).

⚠️ **Перекодування неминуче.** `ffmpeg -c copy` ріже лише по keyframe, а в скрінкастах вони стоять
за секунди один від одного — розріз поїхав би на пів фрази. Тому відео стискається заново профілем
magpress-screencast: `h264_nvenc -cq 28 -preset p6` (без NVIDIA — автоматично `libx264 -crf 28`),
аудіо `aac 96k`. fps і роздільність лишаються як в оригіналі.

Транскрипт кешується поряд у `відео.mp4.words.json` — повторний `--fillers` з іншими порогами GPU
вже не займає. Хочеш перетранскрибувати — видали цей файл.

## 2. Транскрипція окремо — `magcut/transcribe.py`

```bash
python3 magcut/transcribe.py відео.mp4 --language uk --model large-v3
```

Дає `відео.mp4.words.json`: слова з тайм-кодами (`w`, `s`, `e`, `p`) і тексти сегментів.
На RTX-класі — близько **5× realtime**, тобто 45-хвилинне відео ≈ 10 хвилин.

| прапорець | дефолт | що робить |
|---|---|---|
| `МЕДІА` | — | шлях до аудіо/відео (позиційний) |
| `--out FILE` | `<медіа>.words.json` | куди писати JSON |
| `--model NAME` | `large-v3` | назва моделі faster-whisper або локальний шлях (`small`, `medium`, …) |
| `--model-dir DIR` | HF-кеш у `$HOME` | тека кешу завантажених моделей |
| `--language CODE` | автовизначення | примусова мова, напр. `uk` |
| `--device` | `cuda` | `cuda` або `cpu` |
| `--compute-type` | `float16` | `float16` \| `int8_float16` \| `int8` \| `float32` |
| `--beam-size N` | `5` | ширина beam search |
| `--no-vad` | VAD увімкнено | вимкнути Silero VAD (він глушить галюцинації в довгих паузах) |

## 3. Ділянки — `magcut/regions.py`

Читає JSON, пише список ділянок. Лише stdlib, GPU не потрібен, працює миттєво.

### Паразитні звуки «е-е-е» — `--loud`

⚠️ **Whisper не транскрибує вагання-голосні взагалі.** У транскрипті немає ні «еее», ні «мм» —
модель розтягує **сусіднє слово** поверх паразита. У виміряному прикладі слово «ми» отримало
`1.46–3.80`: 2.34 секунди на два звуки, бо всередині сиділо «е-е-е».

Тому шукати їх за списком слів марно. Робоча ознака — **гучно, але не починається жодне слово**:

```bash
ffmpeg -i відео.mp4 -af silencedetect=noise=-35dB:d=0.15 -f null - 2>&1 | grep silence_ > loud.txt
python3 magcut/regions.py відео.mp4.words.json --no-pauses --no-fillers --loud loud.txt
```

Три фільтри відсіюють звичайне мовлення:

| фільтр | що відкидає |
|---|---|
| початок слова всередині | там реально нове слово, а не тягнучка |
| `--min-filler 0.3` | короткі гучні склади всередині довгого слова |
| `--stretch 2.0` | довгі, але нормальні слова: «аплодисменти» — 0.115 с/символ (медіана), «ми» — 1.17 с/символ (11× медіани) |

Перевірено на живому матеріалі: 2 екання з 2 знайдені, хибних немає.

### Паузи

> **Для пауз транскрипт не використовуй — бери `ffmpeg`.** Заміряно на 26 с української мови:
>
> | метод | знайдено пауз | сумарно |
> |---|---|---|
> | `ffmpeg silencedetect -20dB` | **8** | **10.4 с** |
> | whisper `small` | 6 | 7.7 с |
> | whisper `large-v3` | 3 | 3.9 с |
>
> Причина — whisper розмазує межі слів через паузу, і **сильніша модель робить це гірше**:
> вона впевненіше зшиває фразу. Причому з `p=1.00`, тому `--min-prob` не рятує.

Якщо все ж потрібні паузи з транскрипту — `--gap 0.66` (дефолт), `--min-prob 0.3` допомагає
лише на малих моделях.

### Слова-паразити

`--fillers` — для **слів** («ну», «типу»), які whisper таки транскрибує. Дефолту немає навмисно:
це нормальна лексика, і різати її наосліп означає ламати речення.

```bash
python3 magcut/regions.py транскрипт.json --fillers мій_список.txt --fillers "коротше"
```

Прапорець повторюваний, розділювача немає — кома розірвала б `[еэe]{2,}` навпіл. Слова
нормалізуються перед звіркою (`«Е-е-е,»` → `еее`), тож патерни пиши малими без пунктуації.

### Усі прапорці

| прапорець | дефолт | що робить |
|---|---|---|
| `ТРАНСКРИПТ` | — | `*.words.json` від `transcribe.py` (позиційний) |
| `--out FILE` | stdout | куди писати список ділянок |
| `--gap SEC` | `0.66` | найкоротша беззвучна тиша, що вважається паузою |
| `--min-prob P` | `0.0` | слова з меншою впевненістю не рахуються за мовлення (діє **лише** на паузи) |
| `--no-pauses` | паузи увімкнені | лише паразити |
| `--fillers FILE\|REGEX` | немає | список слів-паразитів: файл (один regex на рядок) або один regex; прапорець повторюваний |
| `--no-fillers` | паразити увімкнені | лише паузи |
| `--loud FILE` | вимкнено | вивід `ffmpeg silencedetect` того ж медіа — вмикає пошук звуків «е-е-е» |
| `--min-filler SEC` | `0.3` | найкоротша гучна беззвучна ділянка, що вважається паразитом |
| `--stretch N` | `2.0` | у скільки разів повільніше за медіану має «тягнутись» слово-господар |
| `--join SEC` | `0` | склеювати ділянки, ближчі за це одна до одної |

Статистика пишеться в stderr — саме по ній калібруються пороги; сам список іде в stdout.

## 4. Застосувати готовий список ділянок

Рендер робить сама команда `magcut` (розділ 1). Якщо ділянки вже пораховані окремо — наприклад
`regions.py` з нетиповими порогами — застосувати їх можна двома шляхами.

### У відео — `ffmpeg`

Окремої команди немає навмисно: це один виклик `ffmpeg` з `select`/`aselect` по ділянках, які
треба **лишити** (див. `magcut/media.py:render`).

### KDEnlive — надбудова, `kdenlive/`

Ріже таймлайн так, що кожна ділянка стає окремим кліпом; нічого не видаляє, поки ти сам не
натиснеш Delete. Довжина відео не змінюється, тож зіпсувати нічого не можна.

```bash
magcut проєкт.kdenlive                                  # своя детекція тиші через ffmpeg
python3 kdenlive/silence_cut.py проєкт.kdenlive --silences ділянки.txt --in-place
```

⚠️ KDEnlive тримає проєкт у пам'яті: перед різанням **збережи й закрий** його, інакше
`Ctrl+S` перезапише зміни інструмента.

Це дві різні команди: `magcut` сам шукає тишу через `ffmpeg` і викликає рушій, а
`silence_cut.py` приймає вже готовий список ділянок (з `regions.py` чи звідки завгодно).

**`magcut ПРОЄКТ.kdenlive` — обгортка з власною детекцією тиші**

| прапорець | дефолт | що робить |
|---|---|---|
| `--media PATH` | усі ресурси проєкту | шукати тишу в цьому файлі (і застосувати до всіх кліпів) |
| `--noise DB` | `-20` | поріг гучності для `silencedetect` |
| `--min-silence SEC` | `0.66` | найкоротша тиша, яку різати |
| `--pad FR` | ~1/6 с під fps проєкту | кадрів паузи лишити з кожного боку |
| `--min-entry SEC` | `0` (усі) | різати лише кліпи, довші за це |
| `--delete` | вимкнено | видалити тишу і склеїти (таймлайн коротшає) |
| `--in-place` | увімкнено | правити файл проєкту на місці |
| `--out FILE` | — | писати в окремий файл замість in-place |

**`silence_cut.py ПРОЄКТ.kdenlive` — рушій, ділянки ззовні**

| прапорець | дефолт | що робить |
|---|---|---|
| `--silences FILE` | **обовʼязковий** | ділянки: два числа в рядку або сирий вивід `silencedetect`. Повторюваний; форма `МЕДІА=FILE` привʼязує набір до одного джерела, без ключа — до всіх кліпів |
| `--in-place` / `--out FILE` | **одне обовʼязкове** | правити на місці або писати в новий файл |
| `--pad FR` | ~1/6 с під fps | кадрів паузи з кожного боку |
| `--edge-margin FR` | `3` | кадрів, які лишаються недоторканими біля країв кліпу |
| `--min-entry SEC` | `0` (усі) | різати лише кліпи, довші за це |
| `--fps N` | з `<profile>` проєкту | перекрити частоту кадрів |
| `--delete` | вимкнено | видалити тишу і склеїти замість ізолювати |

Синонім `--regions` = `--silences` (назва «тиша» історична — ділянки можуть бути будь-які).
Біля кожного розрізу навмисно лишається ~0.15–0.2 с тиші.

**Обмеження:** одна пара доріжок (аудіо `playlist2`, відео `playlist4`, групи AVSplit на
доріжках `1,2`). Для інших розкладок — константи вгорі `kdenlive/silence_cut.py`.

## Похибки, про які варто знати

- **Тайм-коди слів неточні** (±0.1–0.2 с) і систематично «розтягнуті». Це компенсує `--pad`
  рушія, тому не став `--pad 0`.
- **Слово на межі медіа** може виглядати як пауза: у прикладі відео обірвалось на
  «аплодисмен», і без `--stretch` це давало хибне спрацювання.
