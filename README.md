# magic-cut

Напівавтоматична нарізка тиші в проєктах **KDEnlive**.

Інструмент **знаходить тихі місця** у відео і **ріже** таймлайн так, що кожна пауза
стає **окремим кліпом**. Сам він **нічого не видаляє** — рішення за тобою: ти
переглядаєш нарізане і видаляєш зайве вручну. Поки ти не видалив — довжина відео не
змінюється, тож зіпсувати нічого не можна.

> **Головна ідея одним рядком:** скрипт робить розрізи → ти слухаєш і видаляєш тихі
> шматки. Аудіо й відео порізані синхронно та згруповані, тож видаляються разом.

---

## 1. Встановлення (один раз)

Це NixOS-пакет у стилі твоїх `mag*`-інструментів. Додай його до `systemPackages`
там само, де підключаєш `magscale`/`magshift`:

```nix
environment.systemPackages = [
  (pkgs.callPackage ./magic-cut { })
  # ... решта mag* ...
];
```

Потім:

```bash
sudo nixos-rebuild switch
```

Після цього з'являються дві речі:
- команда **`magcut`** у терміналі;
- пункт правого кліку **«Вирізати тишу»** для файлів `.kdenlive`.

---

## 2. Як користуватись — покроково

Меню працює **по файлу проєкту `.kdenlive`**, а не по відео. Тому спочатку треба
зробити проєкт із кліпом на таймлайні, а вже потім різати. Повний шлях:

1. **Записав відео** (наприклад, скрінкаст 10 fps) → поклав у теку `Монтаж`.
2. **Відкрив KDEnlive**, створив новий проєкт.
3. **Перетягнув відео** у проєкт і **кинув на таймлайн**.
4. **Зберіг проєкт** (`Ctrl+S`) — наприклад, у теку `Kdenlive Projects`. Тепер у тебе
   є файл `щось.kdenlive`.
5. **Закрив проєкт у KDEnlive** (щоб він потім не перезаписав зміни — див. розділ 4).
6. У Dolphin **ПКМ по `щось.kdenlive` → MagWer Video Toolbox → Вирізати тишу**.
   Відкриється konsole, покаже скільки пауз знайдено — і все.
7. **Відкрив проєкт у KDEnlive знову.** Тепер кліп на таймлайні порізаний на багато
   шматків.

fps визначається автоматично з проєкту — нічого налаштовувати не треба (10 fps, 30 fps
— байдуже).

---

## 3. Що ти побачиш і як видаляти

Після відкриття порізаного проєкту на таймлайні між шматками мовлення з'являться
**короткі окремі кліпи — це паузи/тиша**. Далі вручну:

- Проходишся таймлайном, слухаєш.
- Виділяєш тихий кліп, з яким згоден, і тиснеш **Delete**.
- Аудіо + відео згруповані → видаляються разом.
- Хочеш, щоб дірка одразу зникала (склеювалось) — використовуй **ripple-видалення /
  «Remove space»** замість звичайного Delete.

Біля кожного розрізу навмисно лишається **~0.15–0.2 с тиші** (щоб пауза не зникала
різко, а ставала короткою). Це нормально.

---

## 4. ⚠️ Важливо: перезавантаження проєкту

KDEnlive тримає проєкт **у пам'яті**. Якщо ти різав, поки проєкт відкритий:

- **НЕ** тисни `Ctrl+S` у KDEnlive після різання — він перезапише зміни інструмента.
- Правильно: **закрий проєкт без збереження → відкрий знову**.

Найпростіше правило: перед різанням проєкт має бути **збережений і закритий**.

---

## 5. Якщо ріже не так — що крутити

За замовчуванням: поріг гучності **−20 dB**, мінімальна пауза **0.66 с**. Міняється це
лише через термінал (меню завжди йде з дефолтами):

| Проблема | Що зробити |
|---|---|
| Лишає багато нерозрізаних тихих місць | Підняти поріг: `--noise -18` (ловить тихіше). Або коротші паузи: `--min-silence 0.5` |
| Ріже занадто агресивно, чіпляє мовлення | Опустити поріг: `--noise -25`. Або довші паузи: `--min-silence 1.0` |
| Лишає забагато/замало паузи біля розрізу | `--pad N` (кадрів з кожного боку). За замовчуванням авто під fps |

## 6. Через термінал (без меню)

```bash
# базово (in-place, −20 dB):
magcut /шлях/проєкт.kdenlive

# з параметрами:
magcut проєкт.kdenlive --noise -18 --min-silence 0.5

# у новий файл, не чіпаючи оригінал:
magcut проєкт.kdenlive --out нарізаний.kdenlive
```

```bash
# одразу видалити знайдену тишу (ripple, таймлайн коротшає) — без ручного перегляду:
magcut проєкт.kdenlive --min-silence 1.0 --delete
```

Прапорці: `--noise DB`, `--min-silence SEC`, `--pad FR`, `--min-entry SEC`
(`0` = різати всі кліпи; `30` = лише довгі суцільні блоки), `--media PATH`, `--out FILE`,
`--delete`.

`--delete` працює і на вже нарізаному проєкті: кліп, який сам цілком є тишею (ізольований
попереднім запуском), видаляється повністю. Тобто «нарізати → подивитись → видалити решту»
робиться двома запусками того самого інструмента.

## 7. Паразитні звуки «Е»/«А» (експериментально) — тека `fillers/`

Тиша шукається по гучності, тому **вагання-голосні** («е-е», «а-а») вона НЕ ловить —
вони гучні, як звичайне мовлення. Для них є **окремий інструмент** у теці `fillers/`
(власний `flake.nix` із faster-whisper + CUDA, незалежний від решти).

Ідея: він шукає місця, де **є гучний звук, але немає жодного розпізнаного слова** —
це майже завжди паразит. Видає список ділянок, який згодовується тому самому рушію:

```bash
cd fillers
chmod +x detect-fillers.sh                              # один раз
./detect-fillers.sh /шлях/відео.mp4 -o fillers.txt      # перший запуск збирає nix-оточення (повільно)
python3 ../silence_cut.py проєкт.kdenlive --silences fillers.txt --in-place
```

⚠️ Це **ще не тестовано на реальному матеріалі** — потрібна відеокарта. Коли дійдуть
руки — калібруємо `--min-filler`, `--noise`, `--model`.

---

## 8. Як воно працює всередині (для допитливих)

1. `ffmpeg silencedetect` → інтервали тиші (аналіз **аудіо**, не картинки).
2. Кожен довгий кліп ріжеться на `мовлення / тиша / мовлення`, тиха частина
   підрізається на `--pad` кадрів з боків (щоб лишити коротку паузу).
3. Аудіо- і відео-доріжки ріжуться однаково, групи AVSplit перебудовуються.
4. Перед записом перевіряється валідність XML і що довжина таймлайну не змінилась —
   тобто файл ніколи не псується (а якщо щось не так — просто не записує).

**Обмеження:** розраховано на проєкт з **одним відео** (аудіо на `playlist2`, відео на
`playlist4`, групи AVSplit на доріжках `1,2`). Для інших розкладок — константи вгорі
`silence_cut.py`.

## Файли

- `silence_cut.py` — рушій (Python, лише stdlib). Ріже проєкт за списком ділянок.
- `cut-silences.sh` — обгортка: `ffmpeg silencedetect` + виклик рушія. Потребує
  `ffmpeg` + `python3` на PATH (команда `magcut` їх дає сама).
- `default.nix` — пакує команду `magcut` + пункт правого кліку.
- `fillers/` — окремий інструмент детекції паразитних звуків (див. розділ 7).
